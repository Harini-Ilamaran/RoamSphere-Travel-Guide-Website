# RoamSphere Travel Guide Website - README

## Overview
RoamSphere is a travel guide website designed to help users discover and explore exciting destinations around the world. This project showcases various travel locations with detailed information, images, and travel tips.

## Features
- Responsive design that works on desktop, tablet, and mobile devices
- Interactive destination cards with hover effects
- Organized sections for different travel categories
- Clean, modern UI with appealing visuals
- Easy navigation through the travel guide

## Technologies Used
- HTML5
- CSS3 (including Flexbox and CSS Grid)
- JavaScript (for interactive elements)
- GitHub Pages (for deployment)

## How to Use
1. Clone the repository:
   ```
   git clone https://github.com/harini-ilamaran/RoamSphere-Travel-Guide-Website.git
   ```
2. Open `index.html` in your browser to view the website locally
